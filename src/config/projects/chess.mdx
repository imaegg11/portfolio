A chess game built in python from scratch with pygame for graphics and stockfish to support communications between the chess bot. Everything is handle by the program itself and all ruleset have been implemented, with the sole exception of promotion to pieces other than queens. Draws are based on the implementation by Lichess.

While stockfish supported is implemented, allowing for users to play against the chess bot, controlling the level of difficulty may be broken. Never quite figured it out. 

The core game was made over one long weekend as a way to improve my python skills, with later minor additions to improve the gameplay and iron the bugs. While it may not be the best code written by a long shot, it was basically my first complete project that I had created. Lots of bugs and frustrations happened along the way but it was a good learning experience to have :)
