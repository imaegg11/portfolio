Project Metropolis is WLMAC's student run information hub, offering club data and event updates on all the things going around the school. Built using Python with Django and a sqlite database. 

Joining as member and eventually becoming a backend lead, I worked on automation, including scraping events and integration with AI for automatic tagging.
